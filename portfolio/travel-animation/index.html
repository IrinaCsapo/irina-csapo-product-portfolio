Travel Animation

How-to animation created for Holiday Discounts Platform managed by Sodexo. The platform comes as an employee benefit, both internally and externally available to beneficiaries. I created this animation using a number of available resources, as well as newly created scenes that explain how to book a holiday through the platform.
